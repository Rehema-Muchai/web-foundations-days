# Course Reflection

Reflecting on this full-stack and systems design journey, the most challenging concept for me was mastering database concurrency and race conditions—specifically understanding how multiple users trying to write to the same resource simultaneously can cause data corruption or double-booking if transactions and isolation levels aren't handled correctly. I overcame this by breaking down how database locks, atomic operations, and Redis caching interact under high load through practical architectural models.

Reviewing my capstone project and the feedback received, the key area I would improve is implementing more robust error handling and defensive input validation across both the client-side forms and API controllers to ensure smoother user feedback during edge cases.

Moving forward, I plan to dive deeper into advanced cloud infrastructure, microservices architecture, and automated CI/CD deployment pipelines to scale applications more reliably in production environments.
